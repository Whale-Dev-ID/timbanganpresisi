Software Jembatan Timbang CCTV Anti Manipulasi

Whale JTO Pro adalah software jembatan timbang CCTV yang menggabungkan aplikasi desktop operator, dashboard monitoring browser, dan integrasi kamera dalam satu sistem. Setiap transaksi didokumentasikan dengan snapshot otomatis, membuat operasional timbang Anda anti manipulasi.

Aplikasi desktop untuk operator

Tampilan operator dirancang untuk kecepatan. Tiga mode transaksi — masuk, keluar, biasa — dalam satu layar, dengan berat terbaca langsung dari indikator.

  • Timbang masuk, keluar, dan biasaMode transaksi dalam satu layar tanpa pindah aplikasi.
  • Berat realtime dari indikatorTerhubung universal via Serial/COM ke berbagai merk indikator.
  • Pending transactionTimbang pertama disimpan sebagai pending sampai timbang kedua selesai.
  • Preview tiket sebelum cetakOperator melihat tampilan tiket sebelum mencetak, mengurangi kesalahan.

Dashboard monitoring dari browser

Supervisor tidak perlu berada di komputer operator. Ringkasan transaksi, histori, laporan, dan status realtime tersedia dari browser — dapat dipantau dari mana saja.

  • Total transaksi selesai vs pendingStatus operasional terlihat sekilas dari satu layar.
  • Total netto harianRekapitulasi netto otomatis per hari operasional.
  • Riwayat per tiket, kendaraan, customerPencarian dan filter riwayat transaksi yang lengkap.
  • Export Excel dan cetak PDFLaporan siap pakai untuk manajemen dan audit.

CCTV live view hingga 4 kamera

Pantau area timbang secara langsung dari aplikasi desktop maupun browser. Sistem terhubung hingga 4 kamera via RTSP — IP camera atau kanal NVR, merek apa pun.

  • Live view hingga 4 kamera via RTSPTampilan langsung multi-kamera dalam satu layar monitoring.
  • Kamera IP atau kanal NVR, merek agnostikTidak terkunci pada satu merek perangkat kamera.
  • Dibuka dari desktop dan browserMonitoring fleksibel dari pos operator maupun ruang supervisor.
  • Arsitektur client-serverDesktop & CCTV di pos timbang, dashboard web terpusat di server untuk pantauan manajemen. Tanpa recording/playback — itu fungsi NVR.

Snapshot otomatis per fase timbang

Setiap fase timbang — timbang 1 dan timbang 2 — otomatis menyimpan snapshot dari kamera yang dipilih, terhubung langsung dengan nomor tiket transaksi.

  • Snapshot otomatis per fase timbangBukti foto diambil dari kamera yang dipilih saat transaksi tersimpan.
  • Terhubung dengan nomor tiketFoto bukan file lepas — terikat langsung pada data transaksi.
  • Dibuka dari histori transaksiFoto bisa dilihat dari detail histori saat ada sengketa atau audit.
  • Format JPEG, tersimpan di serverFoto tidak tercetak di tiket; arsip tetap rapi di server.
  • Kamera offline tidak membatalkan transaksiJika kamera gagal, transaksi timbang tetap tersimpan — operasional tidak terganggu.

Untuk siapa Whale JTO Pro

Dirancang untuk perusahaan menengah hingga enterprise — pabrik, tambang, dan logistik — yang membutuhkan dokumentasi visual dan monitoring terpusat atas seluruh operasional timbangnya.

  • Multi operator dan hak aksesAktivitas setiap operator tercatat dengan audit trail.
  • Cetak ulang dengan token ORIGINAL vs COPYSetiap cetakan tiket bisa dilacak keasliannya.

Pertanyaan Umum

Bagaimana cara kerja integrasi CCTV di Whale JTO Pro?

Whale JTO Pro terhubung ke hingga 4 kamera IP atau kanal NVR via RTSP. Setiap fase timbang (timbang 1 dan timbang 2), sistem otomatis mengambil snapshot dari kamera yang dipilih dan menyimpannya bersama data tiket transaksi.

Merk indikator apa yang didukung Whale JTO Pro?

Whale JTO Pro mendukung koneksi universal via Serial/COM — kompatibel dengan AND, Ohaus, CAS, Mettler Toledo, Excell, GSC, Sonic, Fujitsu, dan mayoritas merk indikator lainnya.

Apakah Whale JTO Pro butuh koneksi internet?

Whale JTO Pro memakai arsitektur client-server: aplikasi desktop di pos timbang, CCTV, dan dashboard web yang terpusat di server perusahaan Anda — manajemen dapat memantau transaksi dari mana saja. Penempatan server menyesuaikan kondisi jaringan di lokasi Anda, dibahas saat konsultasi.

Apakah Whale JTO Pro cocok untuk operasional saya?

Whale JTO Pro dirancang untuk perusahaan menengah hingga enterprise — pabrik, tambang, dan logistik — yang membutuhkan dokumentasi visual dan monitoring terpusat atas operasional timbangnya. Ceritakan kebutuhan Anda via WhatsApp, kami rekomendasikan tanpa biaya.

Apakah kamera offline membatalkan transaksi?

Tidak. Jika kamera gagal capture, transaksi timbang tetap tersimpan. Operasional selalu jadi prioritas.

Apakah tiket Whale JTO Pro bisa dicetak ulang?

Ya. Whale JTO Pro mendukung cetak ulang dengan token audit yang membedakan cetakan ORIGINAL dan COPY.

Siap mengamankan operasional timbang Anda?

Konsultasi gratis — ceritakan skala operasional dan kebutuhan monitoring Anda, kami bantu pilih konfigurasi yang tepat.
