FAQ — Pertanyaan Umum

Apa itu software jembatan timbang?

Software yang mengelola penimbangan kendaraan secara digital. Mencatat bruto, tara, dan netto otomatis, menyimpan riwayat transaksi, dan mencetak tiket timbang sebagai bukti resmi.

Bagaimana cara kerja integrasi CCTV di Whale JTO Pro?

Whale JTO Pro terhubung ke hingga 4 IP Camera atau kanal NVR via protokol RTSP. Setiap kali transaksi timbang berhasil disimpan, sistem otomatis mengambil screenshot dari kamera yang dipilih dan menyimpannya bersama data transaksi. Foto bisa dilihat langsung dari riwayat transaksi.

Apa bedanya keempat varian Whale JTO?

Standard untuk operasional harian dasar dengan database lokal. Smart Scanner untuk volume tinggi dengan input barcode. Multi Item untuk kendaraan bermuatan campuran dalam satu tiket. Pro untuk enterprise dengan database terpusat PostgreSQL, dashboard web, dan CCTV.

Apakah bisa digunakan tanpa internet?

Ya. Semua varian Whale JTO dirancang untuk operasional jaringan lokal dan tidak membutuhkan koneksi internet untuk operasional harian.

Merk indikator timbangan apa yang didukung?

Semua varian mendukung koneksi universal via Serial/COM dengan konfigurasi parsing fleksibel — kompatibel dengan AND, Ohaus, CAS, Mettler Toledo, Excell, GSC, dan mayoritas merk lainnya.
