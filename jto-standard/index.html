Software Jembatan Timbang Desktop untuk Operasional Harian

Whale JTO Standard adalah software jembatan timbang desktop untuk operasional timbang masuk, keluar, dan biasa harian. Label transaksi yang fleksibel dan berjalan 100% offline membuatnya cocok untuk UKM hingga perusahaan menengah.

Fitur Utama

Yang paling dicari dari operasional timbang harian.

  • Tiga mode transaksiMasuk, keluar, dan biasa dalam satu aplikasi; netto dihitung otomatis (bruto − tara) dengan pending transaction untuk timbang kedua.
  • Label dan field fleksibelAdmin mengubah label mode transaksi dan 8 field netral tanpa mengubah struktur database; form, riwayat, export Excel, dan printout mengikuti label yang tersimpan.
  • Master data lengkapKendaraan, pelanggan/supplier, ekspedisi, jenis truk, barang, driver, dan operator; import/export master via Excel.
  • Koneksi indikator universalBerat dibaca via Serial/COM dengan parsing start/stop index; tab Hardware Link untuk setting teknis, angka berat besar di tab Timbang untuk operator.
  • Template tiket kustomEditor layout tiket (posisi, area, alignment, style, token @FIELD01–@FIELD08) dengan preview sebelum cetak.
  • Trial 99 transaksiBerjalan tanpa lisensi hingga 99 transaksi selesai; aktivasi lisensi offline berbasis RSA (device ID), tanpa perlu internet.

Cocok untuk

UKM hingga perusahaan menengah — pabrik, gudang, dan tambang skala kecil — yang butuh sistem timbang desktop fleksibel untuk operasional harian dan berjalan penuh secara offline.

Pertanyaan Umum

Apakah Whale JTO Standard butuh koneksi internet?

Tidak. Aplikasi berjalan 100% offline: database SQLite tersimpan lokal di komputer, dan aktivasi lisensi pun dilakukan offline via RSA.

Apakah ada masa trial?

Ada. Anda bisa memakai penuh hingga 99 transaksi selesai tanpa lisensi. Setelah itu, aktivasi lisensi offline berbasis RSA.

Indikator timbangan merk apa saja yang didukung?

Koneksi universal via Serial/COM — kompatibel dengan AND, Ohaus, CAS, Mettler Toledo, Excell, dan lainnya.

Apakah label mode dan field transaksi bisa diubah?

Bisa. Admin mengubah label mode transaksi dan 8 field netral langsung dari aplikasi, tanpa mengubah struktur database maupun logika transaksi.

Apa bedanya dengan Whale JTO Smart Scanner?

Basisnya sama, tetapi Smart Scanner menambah input via barcode untuk operasional bervolume tinggi; Standard mengandalkan input manual untuk operasional harian biasa.

Tertarik dengan Whale JTO Standard?

Ceritakan kebutuhan timbangan Anda — kami bantu memilih varian dan skema lisensi yang pas.
