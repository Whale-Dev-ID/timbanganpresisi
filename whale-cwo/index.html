Software Check Weighing untuk QC & Packaging Line

Whale CWO adalah software check weighing untuk QC dan packaging line. Setiap produk yang ditimbang langsung dinilai PASS, UNDER, atau OVER — cepat, stabil, dan berjalan offline 24 jam.

Fitur Utama

Penilaian lulus/tidak lulus dalam sekejap, langsung di line.

  • Display berat realtimeAngka berat besar (±80px) dibaca via COM port — terbaca jelas operator dari jarak jauh.
  • Indikator PASS/UNDER/OVERLabel hasil besar berwarna: UNDER oranye, PASS hijau, OVER merah.
  • Dua mode transaksiMode Weighing: target = berat satuan × qty, lulus jika dalam target ± toleransi, auto-save saat PASS stabil ±1,5 detik. Mode Qty: tanpa target/status, qty read-only dari database, simpan manual.
  • Master Item lengkapKode/nama item, berat satuan, qty default, toleransi, min/max weight, shelf life, status, dan mode transaksi.
  • Laporan dan struk kustomFilter tanggal/item/status/mode, export CSV, print laporan; Print Layout Editor dengan variabel @..., live preview, test print, logo perusahaan, dan barcode Code 128 asli.
  • Login role & lisensiRole administrator/operator dengan hash SHA-256 (password default wajib diganti saat login pertama); trial 100 transaksi + aktivasi offline RSA.

Cocok untuk

Packaging line, industri makanan, manufaktur, dan area QC yang butuh penimbangan periksa yang cepat, stabil, dan berjalan 24 jam offline di komputer industri.

Pertanyaan Umum

Apakah Whale CWO butuh koneksi internet?

Tidak. Aplikasi 100% offline dengan database SQLite lokal — cocok untuk komputer industri di line produksi yang berjalan 24 jam.

Apakah ada masa trial?

Ada: 100 transaksi tanpa lisensi. Lisensi penuh diaktivasi offline via RSA.

Apa perbedaan Mode Weighing dan Mode Qty?

Mode Weighing menilai hasil terhadap target (berat satuan × qty) ± toleransi dan menyimpannya otomatis saat PASS stabil ±1,5 detik. Mode Qty hanya mencatat tanpa penilaian — qty read-only dari database, simpan manual.

Bagaimana Whale CWO memastikan hasil yang stabil?

Pada Mode Weighing, transaksi tersimpan otomatis hanya saat hasil PASS stabil selama ±1,5 detik — menekan kesalahan baca saat produk masih bergerak di atas timbangan.

Apakah format struk bisa disesuaikan dengan perusahaan?

Bisa. Print Layout Editor visual dengan variabel @..., live preview, test print, logo perusahaan, dan barcode Code 128 asli.

Tertarik dengan Whale CWO?

Ceritakan kebutuhan QC dan packaging line Anda — kami bantu menilai apakah Whale CWO cocok untuk line Anda.
